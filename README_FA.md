# نسخه آزمایشی ضبط ویس برای شبکه محلی

این بسته شامل پچ برنامهٔ PHP و پروژهٔ اندروید است.

## راه‌اندازی سرور

1. روی گوشی میزبان، AWebServer و MySQL را مثل قبل اجرا کنید. IP شبکهٔ همان گوشی و پورت وب (مثلاً `192.168.1.9:8080`) را پیدا کنید. `0.0.0.0` را به‌عنوان IP وارد نکنید.
2. از `index.html` و `assets/app.js` فعلی نسخهٔ پشتیبان بگیرید. فایل‌های پوشهٔ `server-patch` را در مسیر متناظر روی سرور کپی کنید. سایر فایل‌های PHP و دیتابیس را تغییر ندهید.

## ساخت APK با گوشی و GitHub Actions

1. محتویات داخل پوشهٔ `lan-messenger-apk-full` را به ریشهٔ یک مخزن GitHub آپلود کنید؛ پوشهٔ `.github/workflows` هم باید در ریشه باشد.
2. در GitHub بروید به **Actions → Build LAN Messenger APK → Run workflow**. بعد از اتمام، از بخش Artifacts فایل `LAN-Messenger-debug-apk` را دانلود و APK داخل آن را نصب کنید.
3. روی هر گوشیِ کاربر، APK را نصب کنید، اجازهٔ Microphone را بدهید و IP و پورت سرور میزبان را وارد کنید. همهٔ گوشی‌ها باید روی یک شبکه باشند و AWebServer اتصال از شبکهٔ محلی را بپذیرد.
4. وارد چت شوید، روی میکروفون بزنید تا ضبط شروع شود و بار دوم بزنید تا متوقف شود. فایل باید در پیش‌نمایش ظاهر شود؛ سپس با دکمهٔ ارسال، آن را بفرستید.

## چه چیزی تغییر کرده؟

در APK ضبط با `MediaRecorder` خود اندروید انجام می‌شود، نه `getUserMedia` مرورگر؛ بنابراین ضبط در IP محلی HTTP به مجوز میکروفون و پل بومی برنامه وابسته است و به secure-context مرورگر وابسته نیست. فایل ضبط‌شده با نام `voice-...m4a` و نوع `audio/mp4` ساخته می‌شود و از مسیر آپلود عادی PHP ارسال می‌شود. در مرورگر عادی روی IP محلی، محدودیت میکروفون مرورگر همچنان برقرار است؛ کاربران باید از APK استفاده کنند.

**محدودیت آزمایش:** در این محیط APK نهایی روی دستگاه واقعی ساخته و اجرا نشده است. ابتدا با یک گوشی دیگر و یک ویس کوتاه تست کنید.
